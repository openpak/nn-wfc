# nn-wfc — archived

This combined service is retired. It has no active deployment or compatibility
gateway. Each WFC protocol now has its own repository, image and release.

See [the active topology and migration guide](https://github.com/openpak/wfc-common/blob/main/docs/service-split.md).

Repository history and old release tags are retained for provenance and rollback.
Do not deploy this repository for a new installation.
